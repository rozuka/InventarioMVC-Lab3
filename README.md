## 🧭 Descripción del proyecto

Este proyecto corresponde al *Laboratorio N°3* de la asignatura Ingeniería de Software I.  
Implementa una *aplicación de consola en Java* para la gestión de un inventario de productos, siguiendo estrictamente el patrón arquitectónico *Modelo-Vista-Controlador (MVC)*.

El objetivo principal es aplicar buenas prácticas de diseño, modularidad y separación de responsabilidades, garantizando la mantenibilidad y escalabilidad del sistema.

---

## ⚙ Funcionalidades principales

- Agregar un nuevo producto  
- Buscar producto por SKU  
- Mostrar todos los productos  
- Eliminar producto  
- Salir del sistema
